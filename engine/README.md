# Lumenveil engine

The renderer (`CoAVolFog.dll`), its `version.dll` loader, the test harness and the setup tool (`tools/lamp_extract`).
It is a modified version of CoAVolFog (https://github.com/jealous-sound/coa-vfog), under the GNU GPL v2; [CHANGES.md](CHANGES.md) lists what
was changed and when.

How to build it: [../docs/BUILDING.md](../docs/BUILDING.md). How it works: [../docs/HOW-IT-WORKS.md](../docs/HOW-IT-WORKS.md).
Every setting is described in `CoAVolFog.ini`.
