# Screenshots

The README shows 45 before/after pairs from this folder:

| File | What |
|---|---|
| `NN-before.jpg` | The plain game, Lumenveil switched off with Ctrl+F12 |
| `NN-after.jpg` | The same moment with Lumenveil on |

`NN` runs from `01` to `45`: `01` to `26` at night, `27` to `45` at dusk, dawn and day. The README shows the pairs
without captions. The pairs here now were taken on a client that also runs
the [Project Reforged](https://projectreforged.github.io/wotlk/) HD texture and model packs and the ReShade preset of
[docs/RESHADE.md](../RESHADE.md), in both shots of each pair;
the README says so above the pairs. They are 1600 × 670 JPEGs at quality 85, without metadata.

## How the pairs are taken

1. Stand still, hide the interface (Alt+Z), and press Ctrl+F12 to see the plain game.
2. Take the "before" screenshot (Print Screen, or ReShade's screenshot key).
3. Press Ctrl+F12 again, wait a second for the fog to settle, and take the "after" screenshot.

Ctrl+F12 switches only Lumenveil. Take the pairs with the plain client, without texture packs or a ReShade preset:
then the pair shows Lumenveil's own work, and the pictures hold only the game's own art. If a pair does use another
mod, say so above the pairs in the README. Weather, clouds and moving creatures change between the two shots, so take
them a few seconds apart.

## Preparing the files

- Same size for both shots of a pair; 1920 pixels wide or less, so the page loads quickly. A 21:9 screen gives
  1920 × 804.
- JPEG at quality 85-90.
- No interface, no character names, no chat, no server or realm name, nothing that shows where the game was played.
- The game's art in the screenshots belongs to Blizzard Entertainment; they are here only to show what the mod does,
  in a non-commercial project (see [LEGAL.md](../../LEGAL.md#screenshots)).
